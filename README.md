# Normal Maps Web

Generador de normal maps con preview de iluminación en tiempo real, 100% en el navegador (un solo `index.html`, sin build ni dependencias).

- Cargá una imagen (o arrastrala) y ajustá profundidad, desenfoque e inversión de X/Y.
- Previsualizá con una luz que sigue al mouse: difusa, especular, ambiente, toon, pixelado.
- Descargá el normal map como PNG.

## Uso local

Abrí `index.html` en el navegador. Para publicarlo: GitHub Pages (Settings → Pages → Deploy from branch → `main` / root).
